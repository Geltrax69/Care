# Care - Elderly Caregiving Booking App (Ongoing)

Care is a Flutter-based mobile app where families can book trusted caregivers for elderly care at home.

This project is currently in active development.

## What the App Does

- Book caregivers for hourly or full-day home care.
- Browse caregiver options and choose based on availability.
- Manage booking flow from request to confirmation.
- Support secure payments and cloud-backed data workflows.

## Current Focus (In Progress)

- Strengthening booking and slot management flows.
- Improving caregiver discovery and profile matching UX.
- Hardening backend integration and production stability.

## Future Plans

- Real-time caregiver tracking and live booking updates.
- Ratings, reviews, and trust score for caregivers.
- Subscription plans for recurring elder care.
- Smart recommendations based on user preferences and history.
- Admin dashboard for operations and dispute handling.

## Tech Stack

- Flutter (mobile app)
- MongoDB / PostgreSQL (database)
- Stripe (payments)
- AWS / Firebase (cloud services)
- Git / GitHub (version control)

## Status

Ongoing project - actively being built and improved.
